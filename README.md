# Q&A Chatbot

## Project Description

This project is a simple Question and Answer chatbot developed using Python and Streamlit.

The chatbot allows users to enter questions and provides answers based on project-specific sample data.

## Technologies Used

- Python 3.12.x
- Streamlit 1.40.1
- python-dotenv 1.0.1
- Requests 2.32.3
- Pydantic 2.10.3

## Features

- Simple chatbot interface
- Question input
- Answer generation from sample data
- Warning for empty questions
- User-friendly Streamlit interface

## How to Run

Create and activate the virtual environment and install the required packages using:

pip install -r requirements.txt

Then run:

python -m streamlit run app.py
